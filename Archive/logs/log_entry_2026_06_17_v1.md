## Lessons / patterns confirmed

- **The producer-side filter is the right place.** Filtering 908 sentinels at Phase 1 ingest is one change to one file; alternative would have been three coordinated patches across Phases 1/2/3 and ongoing schema-drift risk per Gotcha 9.
- **Provenance must be preserved in the master, not the wiki.** The 908 sentinel rows still live in `_master_prescience_scores.csv` with `source_pass` + `scorer_version` columns telling the story. The wiki shows only valid scores. This is the right separation.
- **Pre-flight question — "are the build scripts up to date for this change?" — saved a 3.5h regen.** Catching the sentinel bug BEFORE Phase 1 ran is the difference between a 3.5h clean run and a 3.5h corrupted run + 3.5h recovery.
- **The 865 vs 115 spread is a real definitional question, not a bug.** Logged as decision deferred.
